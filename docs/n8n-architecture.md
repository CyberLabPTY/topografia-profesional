# Arquitectura de automatización

Frontend (GitHub Pages / dominio propio)
→ HTTPS Webhook
→ n8n
→ validación
→ registro de solicitud
→ clasificación por servicio
→ notificación profesional
→ confirmación cliente
→ seguimiento

## Complementos previstos
- Google Maps u OpenStreetMap para ubicación del terreno.
- Google Sheets o PostgreSQL para CRM ligero.
- WhatsApp Business API o proveedor compatible.
- Email transaccional.
- Almacenamiento de archivos con URLs firmadas.
- Panel privado separado del frontend público.
- IA opcional para clasificación y resumen; nunca para sustituir criterio profesional ni emitir resultados técnicos de topografía.
